# Secondary / historic competitions — deferred

Empty season shells for secondary comps (Serie A Elite, Welsh Premiership, AIL,
NL1/NL2, Nationale, Iberian leagues, etc.) are **intentionally not backfilled**
until major competition seasons and player/team media coverage are solid.

Resume later via:

- `npm run import:competition-catalog`
- Wikipedia season scripts for a specific secondary slug
- `npm run import:wikipedia:major-gaps -- --competition=<slug>` when a catalog exists

Do not mass-import 40-year empty shells without standings sources.
